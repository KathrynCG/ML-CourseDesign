## 方法概要

四个任务规模都不大，统一以 ImageNet 预训练骨干做迁移学习，不从头训练：

- **骨干**：ResNet18 为主，另有 EfficientNet-B0、ResNet34、ResNet50、Faster R-CNN（ResNet50-FPN）、UNet（ResNet18 编码器）作对照；
- **增强**：分类任务用随机裁剪、翻转、旋转、颜色扰动、随机擦除；检测与分割任务用图像与标注同步变换；
- **训练**：AdamW，余弦退火或阶梯衰减，按验证集指标保存最佳 epoch，配合早停、梯度裁剪；
- **推理**：多折模型集成，叠加翻转类 TTA，最后按竞赛模板重排提交文件。

各任务的关键判断：

1. **植物分类**：EfficientNet-B0 五折均值 0.9152，高于 ResNet18 的 0.8998；消融显示移除绝大多数模块都会掉分，增强与正则整体是正贡献。消融里换 EfficientNet 为 −0.0101，与五折方向相反——原因是消融沿用了 baseline 的 30 轮 / patience 5，而主流程用 40 轮 / patience 10，同一折差 0.0200 全部来自训练预算。
2. **表情识别**：输入分辨率影响最大（224 → 64 掉 3.2 个百分点）；按类别倒数的重采样在 Accuracy 下有害，关闭后验证集升 1.25 个百分点，但线上没有体现（0.678 → 0.679）。
3. **黄斑定位**：bbox 中心与真值偏差 ΔX=0.607±1.318、ΔY=1.316±1.864，直接把框中心当坐标的训练集 RMSE 为 1.903 px，因此把坐标回归改写为“检测框取中心”。同配置两次运行五折均值 13.96 与 33.00，折间方差是主要矛盾。
4. **血管分割**：损失用 0.3×BCE + 0.7×Tversky（α=0.3、β=0.8），β>α 加重漏检惩罚；提交必须存 PNG 二值掩码，避免有损压缩改变前景像素。

## 复现说明

- 环境：Kaggle Notebook，GPU 为 NVIDIA Tesla T4；PyTorch + torchvision，分割任务用 `segmentation_models_pytorch`，检测任务用 torchvision 的 Faster R-CNN，增强用 albumentations。
- 随机种子：数据划分与模型初始化在可设置的环节固定为 42。
- 数据：由课程在 Kaggle 竞赛页提供，未使用任何外部数据；数据与训练权重不随仓库分发。
- 各 notebook 内按 Cell 顺序执行即可复现训练与提交文件；报告中的每个数字都能在对应 notebook 的输出里找到。
