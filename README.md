# 机器学习课程设计：四项 Kaggle 任务的建模与优化

东北大学《机器学习》课程设计。四个任务均以 Kaggle 竞赛形式给出，代码以 Jupyter Notebook 形式保存于 `notebooks/` 目录。

## 任务与结果

| 任务 | 问题类型 | 数据规模 | 指标 | 成绩 |
|---|---|---|---|---|
| 小样本植物图像分类（5 类） | 小样本分类 | 训练 500 / 测试 378 | Macro-F1 | 5 折均值 **0.8944** |
| 人脸表情识别（6 类） | 细粒度分类 | 训练 28275 / 测试 7065 | Accuracy | **0.678** |
| 眼底黄斑中央凹定位 | 检测 + 坐标回归 | 训练 80 / 测试 20 | RMSE | 最终榜 **17**（OOF 13.96） |
| 眼底血管分割 | 二值语义分割 | 训练 20 对 / 测试 20 | Dice | **0.77226** |

竞赛主页：<https://www.kaggle.com/neucx11/competitions>

## 方法概要

四个任务规模都不大，统一以 ImageNet 预训练骨干做迁移学习，不从头训练：

- **骨干**：ResNet18 为主，另有 EfficientNet-B0 / ResNet34 / ResNet50 / Faster R-CNN(ResNet50-FPN) / UNet(ResNet18) 的对照；
- **增强**：分类任务用翻转、旋转、颜色扰动；检测与分割任务用图像与标注同步变换；
- **训练**：AdamW / Adam，余弦退火或阶梯衰减，按验证集指标保存最佳 epoch，配合早停与梯度裁剪；
- **推理**：交叉验证多折模型加权平均，叠加 TTA（翻转等），最后按竞赛模板重排提交。

各任务的关键发现：

1. **植物分类**：500 张样本下，集成 + TTA 比换更大骨干更有效；
2. **表情识别**：输入分辨率是最大影响因素（224→64 掉 3 个百分点），`WeightedRandomSampler` 在 Accuracy 指标下反而有害；
3. **黄斑定位**：bbox 中心与中央凹真值偏差仅约 1 px，把坐标回归改写成"检测框取中心"后误差显著下降；
4. **血管分割**：最大单次提升来自把预测 mask 从 JPG 改为 PNG 导出（线上 0.643→0.749），其次是二值化阈值（0.6 最优）。

## 复现说明

- 环境：Kaggle Notebook，GPU 为 NVIDIA Tesla T4；框架 PyTorch + torchvision，分割任务另用 `segmentation_models_pytorch`，检测任务用 torchvision 的 Faster R-CNN。
- 随机种子：数据划分与模型初始化统一固定为 42。
- 数据：由课程在 Kaggle 竞赛页提供，未使用任何外部数据。
- notebook 内按 Cell 顺序执行即可复现训练与提交文件；训练权重按折保存，未随仓库分发。
